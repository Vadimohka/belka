# Беларускамоўная nanochat-мадэль

Гэта шаблон model card для мадэлі, навучанай з дапамогай `belarusian_llm_training_superpack`.

## Мэта

Мадэль павінна адказваць па-беларуску і мякка захоўваць беларускі рэжым пры запытах на іншых мовах.

## Абмежаванні

Smoke-мадэль або кароткі лакальны запуск не з'яўляюцца доказам высокай якасці. Для практычнай мадэлі патрэбны вялікі легальны корпус, працяглае навучанне, незалежная ацэнка і публічнае параўнанне з існымі рашэннямі.

## Даныя

Укажыце канкрэтныя крыніцы, ліцэнзіі, фільтры, долю прынятых/адхіленых дакументаў і SHA256 маніфест навучальнага корпуса.

## Ацэнка

Запусціце:

```bash
python eval/run_openai_compatible_eval.py --base-url http://127.0.0.1:8000 --model be-local
```

і апублікуйце вынікі без рэдагавання.
