# Кароткі тэхнічны змест MeetMesh па-беларуску

MeetMesh — Django/DRF/Celery праект для AI-апрацоўкі Google Meet сустрэч. Ён пабудаваны вакол афіцыйных Google API і робіць паслясустрэчныя артэфакты асноўным вытворчым шляхам.

Асноўныя дамены:

- accounts: карыстальнікі, ўваход, профіль;
- workspaces: працоўныя прасторы, сяброўства, ролі, прыватнасць, retention, notification settings;
- google_integration: OAuth, Google account, Calendar sync, Meet/Drive/Docs/Workspace Events wrappers;
- meetings: сустрэчы, удзельнікі, артэфакты, стэнаграмы, сегменты, summary, action items, decisions, saved searches, exports;
- automation: audit logs, processing jobs, webhook endpoints/deliveries, API tokens, notifications, usage counters;
- api/web: DRF endpoints and web UI routes.

У SFT гэты праект выкарыстоўваецца толькі як крыніца сэнсу. Англамоўны код і дакументацыя не капіруюцца ў беларускамоўны навучальны корпус.
