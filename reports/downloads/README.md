# Download provenance

This directory records checksum/provenance material for source downloads used
during Belka corpus preparation.

The raw downloaded archives are not stored in git. The SHA256 files are retained
as provenance records for owner-managed local data acquisition.

Repository publication does not mean that upstream source materials are relicensed
or freely redistributable. See:

- `DATA_RIGHTS_AND_PERMISSIONS.md`
- `DATA_LICENSES.md`
- `reports/DATA_RIGHTS_MANIFEST.json`
- `reports/public/DATA_PROVENANCE_SUMMARY.md`
