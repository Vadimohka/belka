# Checkpoint hash manifests

This directory stores SHA256 records for Belka checkpoint artifacts.

Checkpoint binaries are not stored in git. Hash files are kept as provenance
records for external or release-managed artifacts. A hash file here does not
mean the corresponding checkpoint is published in this repository.

Current release status:

- Public GitHub repository: code, docs, configs, evals, manifests.
- Model binaries: to be selected and published separately.
- Dataset artifacts: governed by `DATA_RIGHTS_AND_PERMISSIONS.md`,
  `DATA_LICENSES.md`, and `reports/DATA_RIGHTS_MANIFEST.json`.
